# Golabi

**Desktop-first, RTL financial workflow platform for construction contractors.**
Role: Co-Founder & Product Designer · 2025 — Present

This is a showcase repo — the product's codebase is private, but here's an overview of what it is and what I built.

## What it is

Golabi is an accounting and workflow tool built for construction contractors in Iran, with a Persian, right-to-left interface designed around how contractors actually track costs and jobs.

## What I built

- Designed the complete UI/UX system in Figma for contractor workflows
- Built a Persian, RTL-first client in React + Vite + Tailwind CSS, with shadcn/ui components
- Deployed and maintain the stack on a Linux server

## Tech stack

`React` · `Vite` · `Tailwind CSS` · `shadcn/ui` · `PHP` · `Figma` · `Linux`
